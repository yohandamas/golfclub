# 의리 골프클럽 (가제) — 설치 가이드
_현재 버전: v1.4_

## 1. Supabase 설정
1. https://supabase.com 에서 새 프로젝트 생성
2. SQL Editor에서 `schema.sql` 전체 실행 (notices 테이블·self_register RPC 포함)
3. 이어서 `seed_members.sql` 실행 → 중복 없는 전체 회원 명단 등록 (초기비번 전원 0001)
4. 이어서 `seed_schedule_2026.sql` 실행 → 26년 7~12월 정기 일정 등록
5. Project Settings → API 에서 **Project URL**과 **anon public key** 복사

## 2. index.html 연결
`index.html` 하단 `<script type="module">` 안의 아래 두 줄을 방금 복사한 값으로 교체:
```js
const SUPABASE_URL = 'https://YOUR-PROJECT.supabase.co';
const SUPABASE_ANON_KEY = 'YOUR-ANON-KEY';
```

## 3. Vercel 배포
- Vercel New Project → 이 폴더(`index.html` 포함) 업로드 또는 GitHub 연결
- Framework Preset: **Other** (정적 파일이므로 빌드 명령 없음)
- 배포 후 나오는 URL이 실제 사이트 주소

## 4. 첫 로그인 후 할 일
- 마스터(서힘찬)로 로그인 → 운영패널에서 회원 권한/등급 기준값/클럽명 관리
- 각 회원은 로그인 후 헤더의 "🔑 비번변경"으로 비밀번호 변경 권장
- 등급 기준값(85/95/105)은 운영패널에서 언제든 수정 가능

## 5. 로그인이 안 될 때 확인할 것
- `index.html`의 `SUPABASE_URL` / `SUPABASE_ANON_KEY`가 아직 `YOUR-PROJECT` 자리표시자 그대로면 100% 로그인 실패합니다. 반드시 실제 값으로 교체하세요.
- 브라우저 개발자도구 콘솔(F12)에 `login error`로 로그가 찍히는지 확인 — 진짜 에러 원인(네트워크/URL 오타 등)이 여기 나옵니다.
- Supabase Table Editor → `members` 테이블에서 해당 이름의 `password` 값이 실제로 `0001`인지 직접 확인
- 이름은 정확히 일치해야 합니다(띄어쓰기·오타 주의) — 로그인 모달의 "회원 목록" 드롭다운으로 고르면 오타를 줄일 수 있어요

## 6. 현재 버전(v1.4)이 커버하는 기능
- **로그인 없이도 즉시 열람**: 홈(공지·이번 주 일정), 일정 리스트(월별/분기/연간), 랭킹은 로그인 없이 바로 보임
- **로그인**: 회원 목록에서 이름 선택 또는 직접 입력 + 비밀번호, 또는 그 자리에서 이름만으로 즉시 자체 등록(초기비번 0001)
- **헤더 유틸리티**: 🔑 비번변경, 🔤 글자크기(라지 모드), ☀️/🌙 라이트-다크 테마 (설정은 localStorage에 저장되어 다음 방문에도 유지)
- **일정**: 정기·백세클럽·100세클럽·제외 구분, Cc(골프장명)·행정구역·티업시간·시간대·구성원(참가자) 필드, 참석/대기/불참 체크(로그인 필요)
- **공지(운영진 댓글)**: 홈 화면 상단에 관리자 공지/매너 안내 배너 노출, 운영패널에서 추가·삭제
- **스코어/티어**: 최근 5게임 평균 기준 티어 자동 재계산(DB 트리거), 등급별 랭킹 필터
- **마이페이지**: 스코어카드형 최근 라운드, 등급 배지, 히스토리
- **회원별 보기**
- **운영패널** (마스터·운영진 전용): 클럽명 수정, 회원 권한(운영진) 부여/해제, 비밀번호 초기화, 등급 기준값 수정, 공지 관리, 업데이트 내역
